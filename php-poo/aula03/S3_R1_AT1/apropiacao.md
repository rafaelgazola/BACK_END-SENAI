# EXERCÍCIOS DE APROPRIAÇÃO
### Explique com suas palavras o que é herança.
- é quando uma classe herda atributos de uma classe mãe
### Qual a diferença entre private e protected?
- No private apenas a classe pode ter acesso, já no protected as classes filhas também tem acesso
### O que significa sobrescrever um método?
- sobrescrever um método é quando usamos um metodo para outra finalidade, também chamada de polimorfismo
